GitSwitch v1.5.0 brings a History screen that reads like an IDE's git log, a tidier repo list, and optional GitHub sign-in: browse every repo your accounts can see, and HTTPS remotes that use the right account. Everything works as before without signing in.

## Install or update

macOS, Linux, WSL, Git Bash:
```sh
curl -fsSL https://raw.githubusercontent.com/macdipu/gitswitch/main/install.sh | sh
```
Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/macdipu/gitswitch/main/install.ps1 | iex
```
Run the same line again to update. Your accounts, rules and repo choices are kept.

## New

- **History, like an IDE's git log.** The desktop app's History page now uses the whole window, with the account behind every commit as before.
  - A branches panel on the left: local branches, each remote and tags, with folders for names like `feature/login`. Click one to see only its commits, double-click to switch to it, right-click for more. `t` hides it.
  - Branch and tag labels at the end of each row, merge commits greyed, the author's name next to the account, dates like "Today 10:45", and ↑ on commits that are not pushed.
  - Details on the right: the full message, the changed files with their line counts, and a file's diff when you click it. The eye by the changed files groups them by directory, by module (the nearest folder with `go.mod`, `package.json`, `build.gradle`, …) or both, hides the commit's details, and opens diffs in a larger window if you prefer.
  - **Sort and options**: by date or topologically, first parent (a branch's own story), no merges, and collapse linear branches (long straight runs fold into one row you can open).
  - **View**: compact or full labels, tag names, exact dates, labels on the left, which columns to show, and highlighting your commits, merges, the current branch, or a branch's commits not cherry-picked onto the current one yet. Your choices are remembered.
  - Search with `branch:` and `path:`, or Path under Filters, to see one branch's commits or those that changed a file or folder.
- **Sign in to GitHub (optional).** `gitswitch signin <account>`, or "Sign in to GitHub…" in an account's menu, or `g` in the terminal app. GitSwitch checks the token with GitHub, refuses a token of another user than the account's key logs in as, and keeps it only in your OS keychain, never in git config. `gitswitch signin --check` says whether each token still works; `gitswitch signout <account>` removes it.
- **Your GitHub repos.** Once an account is signed in, the Accounts page lists every repo it can see, private and organization repos included, with where each is cloned already. Search and filter by account, owner, language, visibility or clone status, then clone with the right account in one click. Also `gitswitch github list` and `gitswitch github clone <owner/name>`, and `b` on the terminal app's Repos page. Lists are kept for an hour, so they show at once.
- **HTTPS remotes use the right account.** While an account is signed in, git gets its token for the HTTPS remotes of that account's repos, so clone, fetch and push work without a password prompt. Every other repo and host still uses your own credential helper, exactly as before. Signing out or uninstalling takes GitSwitch's helper out again.
- **Update with rebase.** When your branch and its remote both have new commits, `gitswitch update` stops and explains, as before. To put your not-pushed commits on top of the new ones instead, run `gitswitch update --rebase` once, or `gitswitch set pull rebase` to make it the default (`--repo` for one repo). The desktop app offers it when Update stops. It never runs with uncommitted changes or your own merge commits, changes nothing if your commits clash, and can be undone until you push.
- **A tidier repo list.**
  - **Recent repos**: the last 10 repos you opened come first in the History repo menu and the terminal app's repo list. `gitswitch repo recent` lists them.
  - **Groups**: group the list by account, owner, folder or groups you name ("Group by" on the Repos page, `g` in the terminal app, `gitswitch set repo-groups`). `gitswitch repo group <name>` puts a repo in a group.
  - **Sorting**: by folder, name, recently opened or account, pinned repos first ("Sort by", `s`, `gitswitch set repo-sort`).
  - **Several clones of one repo** now say where the others are ("also cloned at …").
