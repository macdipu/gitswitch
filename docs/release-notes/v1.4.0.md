GitSwitch v1.4.0 (in progress) helps with everyday branch work. You can see your uncommitted files at a glance, and you can undo the last change GitSwitch made.

## Install or update

macOS, Linux, WSL, Git Bash:
```sh
curl -fsSL https://raw.githubusercontent.com/macdipu/gitswitch/main/install.sh | sh
```
Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/macdipu/gitswitch/main/install.ps1 | iex
```
Run the same line again to update. Your accounts, rules and repo choices are kept.

## New

- **Smart switch.** When you switch branch with uncommitted changes, GitSwitch asks whether to take them along. Use `gitswitch switch <branch> --smart` to skip the question.
  - When git refuses because your changes would be overwritten, GitSwitch sets them aside, switches and puts them back, staged files staged.
  - If some files clash with the new branch, you fix the conflict markers there, in your editor or IDE, while your original changes stay safe. Then choose **I've fixed them** (`gitswitch resolve --done`), or **Go back** to the old branch with your changes exactly as before (`gitswitch resolve --abort`). The desktop app shows both above the commits, and the terminal app uses `R`.
- **Undo.** Undo the last switch, revert, drop, rollback, cherry-pick or fix-author in a repo. Use the **Undo** button in the message after the change or in the History toolbar. You can also press `Shift+U` in either app, or run `gitswitch undo`.
  - Undo puts the branch back exactly as it was. After a rollback, files you edited since are kept.
  - It refuses, and changes nothing, when undoing would lose work: new commits or a pull since, commits already pushed, or uncommitted changes in files it would change.
  - `git gc` doesn't delete a dropped commit while it can still be undone.
- **Uncommitted files at a glance.** The History toolbar, the terminal app, `gitswitch branch`, `log` and `status` show how many files are staged, changed, new or in conflict. `gitswitch status --json` includes them too.
