GitSwitch
Git is not using GitSwitch yet.
Install once and every terminal and IDE on this computer picks the right account.

    Accounts

    Each account has its own SSH key and commit email. GitSwitch picks one for every clone, pull and push.

    Repos

    Choose an account for each repo. "Follow rules and default" uses your rules, then asks on the next pull or push; "Ask every time" always asks. Adding or removing a repo here only changes GitSwitch's list, never the repo.

    For a repo outside your project folders.
    The account is used from the first download and saved for the repo.

    History

    Every commit with the account that made it. Click a commit to see its message, the files it changed and what you can do with it.

    A remote branch (origin/…) becomes a local branch that tracks it.

    / search · j k move · Enter select · Ctrl/⌘-click select several · Esc clear · b branch · r reload

    Rules

    Rules pick the account automatically, so most repos never ask. A repo's own saved account always wins over rules.

    Settings

    GitSwitch has no background process. Git starts it for a moment on each network command, and this window runs only while it is open.

    A repo can have its own choice: tick “Remember my choice for this repo” when GitSwitch asks, or run gitswitch set switch-changes park --repo.

    Changes are saved right away.
