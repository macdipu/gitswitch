Git is not using GitSwitch yet.
Install once and every terminal and IDE on this computer picks the right account.

Accounts

Each account has its own SSH key and commit email. GitSwitch picks one for every clone, pull and push.

Repos

Choose an account for each repo. Repos set to "Ask" follow your rules, then ask on the next pull or push.

History

The commit graph with the account behind every commit. Commits made with another account's email are marked before you push them.

Rules

Rules pick the account automatically, so most repos never ask. A repo's own saved account always wins over rules.

Settings

GitSwitch has no background process. Git starts it for a moment on each network command, and this window runs only while it is open.
